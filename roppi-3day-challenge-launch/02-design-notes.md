# 設計意図・NGライン・チェックリスト

## 1. 前回ローンチとの関係が、今回の最重要論点

**8月頭に、同じアカウントで1回ローンチしている。**（8日間 → 5日目に体質診断リンク → LINEで結果配布 → 体質別VSL → 個別診断会）

つまり今回は、**同じフォロワーへの1ヶ月で2回目のローンチ**になる。リストは3層に分かれている。

| 層 | 状態 | 打ち手 |
|---|---|---|
| A. 前回LINE登録済み・診断会に来なかった | VSLの教育が**すでに入っている** | **いちばん熱い層。** ストーリーだけでなく**LINEからも同時に配信する**（下記） |
| B. 前回ストーリーは見たが登録しなかった | 「またやってる」と見える危険 | 1-1で**前回に触れて感謝から入る。** 無かったことにしない |
| C. 今回が初見 | 前提ゼロ | 5-2の「前回の診断を受けてなくても大丈夫」で拾う |

### やってはいけないこと

**前回に一切触れずに新企画を出すこと。** 1ヶ月で2回目なので、触れないと「また何か始めた」に見える。
1-1を**前回への感謝から開く**のは、これがいちばん安い保険だから。

### ★ LINE配信を忘れると、いちばん熱い層を丸ごと落とす

`【要確認】` **3日間チャレンジのLINEは、前回の体質診断と同じアカウントか、別アカウントか。**

- **同じアカウントなら：** A層はすでに友だち登録済み。**ストーリーのリンクを踏む必要がない**ので、リンクスタンプ経由では拾えない。**LINE側から目標シートを直接配信すること。**
- **別アカウントなら：** A層にも登録し直してもらう必要がある。**前回アカウントから今回アカウントへの誘導配信が必須。**

**ここを設計しないと、VSLで教育済みのいちばん濃い層を、まるごと取りこぼす。**

## 2. 前回VSLの「3つの課題」が、今回の位置づけを決めている

前回VSLは「人生最後のダイエットに必要な3つの課題」を立てた。

| 課題 | 前回 | 今回の3日間チャレンジ |
|---|---|---|
| ① 自分の**体質**を正しく知ること | **診断＋VSLで無料解決済み** | − |
| ② 体質と生活に合った**継続できる方法**を持つこと | 「この動画では答えられません」→ 診断会へ | **目標シート＋宿題がこれ** |
| ③ **独りにならない環境**を持つこと | 診断会・サポートへ | **毎日21時のチェックがこれ** |

**これが今回のローンチで最大の資産。**

VSL⑩は「じゃあ具体的に"私の場合"は、何から、どのくらい、どうやればいいの?」と問いを立てて、**答えずに診断会に送っている。**
今回のチャレンジは、**その問いに無料で答える企画**として置ける。だから 1-1 でその質問をそのまま出す。

そして VSL⑨ は「独りにならない環境は、用意された場所に自分から入るしかない」と言い切っている。
**毎日21時のチェックは、まさにそれ。** 4-2 でこれを言語化するのが、15投稿でいちばん強い一手。

**前回VSLを見た人は、「②と③が要る」と自分で結論を出している。** そこに無料でその一部が届く。
他人に言われた主張は反論されるが、**自分で出した結論は反論されない。**

## 3. この5日間が解いている、もう一つの問題（到達率）

ローンチの成否は「3日目にリンクを何人がタップしたか」ではなく、**「3日目に、ストーリーが何人に届いたか」**でほぼ決まる。

Instagramのストーリーは**直近で反応した人から順に上位表示される。**
つまり3〜5日目の到達率は、**1〜2日目にどれだけスタンプを押させたかの結果として後から決まる。**

| Day | 表向き | 実際にやっていること |
|---|---|---|
| 1 | 重大発表 | **アンケート2回で反応値を作る**（配信の器を広げる） |
| 2 | 予告 | カウントダウンで**通知を予約**させる（見ていない人を3日目に呼び戻す） |
| 3-5 | ローンチ・煽り | 1〜2日目で広げた器に、リンクを流し込む |

**1日目・2日目にスタンプを1つも置かない台本は、それだけで3日目の到達が落ちる。**
「まだ売らない日」ほど、仕掛けを必ず入れること。

なお、ろっぴさんの直近ストーリーは**1,000回超の閲覧**（7/8時点）。ここが基礎値なので、
**1-1の閲覧数と3-2の閲覧数を比べれば、1〜2日目の設計が機能したかが一目で分かる。**

## 4. 「MEL設計」という呼称をどうするか

`【要確認】` **前回「体質別・4タイプ・東洋医学」という世界観を打ち出したばかり。**
1ヶ月後に「MEL設計」という別のフレーム名が並ぶと、**世界観が2つになって薄まる。**

選択肢は3つ。

| 案 | 内容 | 評価 |
|---|---|---|
| **A（推奨）** | ストーリーでは呼称を出さず、**「体質診断の"その先"」**として機能だけ言う | **世界観が割れない。** 名前は参加後（LINE・チャレンジ本編）で出せばいい |
| B | 「MEL設計」を出し、**体質の枠内**として説明する（例：体質タイプ別に、量を設計する考え方） | 使えるが、ストーリー1枚で説明しきるのは重い |
| C | 「MEL設計」を独立した新フレームとして立てる | **非推奨。** 前回の体質診断が1ヶ月で古い話になる |

**現行の台本はA。** MELの正式な意味（頭文字）を教えていただければ、Bの言い回しも作ります。
意味が伝わる略語は、伝わらない略語の3倍強い。逆に**意味の伝わらない3文字は、ストーリーでは完全に素通りされる。**

## 5. 「煽り」を、どう煽らずに実装したか

ご要望は4日目・5日目が「煽り」。
ただし前回VSLでろっぴさんが確立しているトーンは、**「責めない」**（「意志が弱いんじゃないんです」「責められないんです」「あなたがダメなんじゃなくて」）。
ゴリゴリの煽りを入れると、次の2つが起きる。

- 平常運転のフォロワーが**5日間で一気に冷める**（ローンチは終わってもアカウントは続く。しかも**1ヶ月で2回目**）
- 集まるのが「煽られて入った人」になり、**3日間の宿題をやらない＝体験会に来ない**

そこで、煽りの機能だけ残して形を変えた。

| 一般的な煽り（不採用） | 本台本での実装 | 置いた投稿 |
|---|---|---|
| 「残り◯名！」 | **人数の限定は書かない**（下記の条件付き）。期日だけで押す | 3-2 / 5-1 |
| 「もう二度とやりません」 | 触れるなら「いまのところ決まっていません」 | 5-1 |
| 「このままだと一生痩せません」 | **「5年後のあなたから見たら、今日が一番若くて一番痩せやすい日」**（VSL⑫原文） | 5-3 |
| 「その一歩を踏み出さなかった結果が今のあなたの体型です」（VSL⑫にある） | **ストーリーでは使わない。** VSLは見ると決めた人の60分だから成立する。ストーリーは通りすがりの2秒で、同じ言葉が非難として届く | − |
| 「本気の人だけ来てください」（VSL⑫） | 今回は**無料チャレンジで入口が広い**ので使わない。あれは有料前の絞り込みの言葉 | − |
| 「3日で−2kg！」 | **「痩せません」と自分から言う** | 5-2 |
| 「参加者殺到中！」 | **参加者の"理由"を見せる**（数ではなく中身。全員ちがう＝個別最適の証明） | 4-1 |

### 人数限定を使う場合の条件

前回VSLは「お一人にかける時間が長いぶん、**枠に限りがあります**」「**3日間限定**」を使っている。
今回も使ってよいが、**条件は「実際に上限を設けること」。** 上限が無いのに「残り◯名」は書けない（景表法）。

`【要確認】` **3日間チャレンジに人数上限を設けるか。** 21時のチェックを人力で回すなら、実際に上限があるはず。
あるなら 3-2・5-1 で使えるので、数字を教えてください。

## 6. 最大の離脱ポイントは「シート未入力」

導線は **登録 → 目標シート入力 → 宿題** で、**シートが埋まらないと宿題が出せない＝そこで死ぬ。**
登録数だけ見ていると気づかないので、**KPIは登録数ではなくシート入力完了数**で置くこと。

台本では3箇所で先回りしている。

| 投稿 | 打ち手 |
|---|---|
| 2-2 | **シートの画面スクショを、登録前に見せる。** 届いた瞬間の「なんか始まった」感を消す |
| 2-2 / 3-2 | **「入力すれば翌朝あなた専用の宿題が届く」** ＝ 作業ではなく**受け取り**として提示する |
| 3-2 | 参加手順を**3ステップで固定**（①登録 ②入力 ③翌朝宿題）。手順が見えていないものは後回しにされる |

**追加で必ずやること：** LINE登録直後の1通目を「シート入力だけ」に絞る。
挨拶・自己紹介・世界観の説明を1通目に混ぜると入力率が落ちる。**1通目 = 1アクション。**

## 7. 無料体験会を、いつ開示するか

3日間チャレンジの最終目的は無料体験会の予約。一方でストーリー15投稿では体験会に一切触れていない。**意図的。**

- **触れない：** 参加率は最大化されるが、3日目に「聞いてない」が発生する
- **最初から言う：** 「結局セールスか」で登録率が落ちる。**しかも前回すでに診断会へ送っているので、B層には「また同じ流れ」と読まれる**

**推奨：ストーリーでは言わない。LINE登録直後（または目標シートの最後）に、1行だけ事実として置く。**

> 「3日目に、ご希望の方だけ無料体験会のご案内をします。」

こうすると、
- ストーリーの熱は落ちない（募集の文脈にノイズが入らない）
- 「聞いてない」は発生しない（登録した全員が最初に見ている）
- **「ご希望の方だけ」で逃げ道が立っている**ので警戒されない

IBLDが体験会を初日から解放しているなら、「3日目に案内」を「いつでも予約できます」に変えるだけでこの1行はそのまま使える。

**4-2で絶対にやってはいけないこと：** 21時チェックの話の締めで、その先（診断会・有料サポート）に触れること。
VSL⑨は「独りにならない環境は、用意された場所に自分から入るしかない」→ 有料サポートへ、という流れだった。
**同じ流れをストーリーでやると、4-2が丸ごとセールスに見える。** 締めは「3日間だけですけど、その環境、こっちで用意します」で止める。

## 8. ストーリー運用の実務ルール

### 文字量
- **1投稿 = 1メッセージ。** 言いたいことが2つあるなら2投稿に割る
- 1枚の文字数は**80字前後まで。** それ以上はスキップされる（読まれるのは平均2〜3秒）
- **4-2だけは動画にする。** 文字量が多く、かつ最も感情が動く箇所なので、声で伝える価値が最大

### 配置
- **上端15%・下端20%には文字を置かない**（アカウント名とDM入力欄に隠れる）
- リンクスタンプは**中央〜やや下**
- **リンクスタンプの投稿には、他のスタンプを置かない**（タップ先が割れる）

### 顔出し・動画
- **1-1 / 4-2 / 5-3 は顔出し**（初日と最終日を対にし、中日に動画を1本）
- 全15投稿テキストだけだと滞在時間が伸びず、到達率が落ちる
- インタビューで依頼済みの素材（台所などの日常風景、トレーニングウェア姿）を背景に使うと、**一目でろっぴさんのアカウントだと分かる**

### ハイライト
- **1投稿目から全部、ハイライト「3日間チャレンジ」に保存する**
- 途中から見た人・4日目に気づいた人の受け皿。ここが無いと後追い組を全部落とす

### プロフィール
- ローンチ期間中は**プロフィールURLもLINE登録リンクに変更**する

### DM自動応答
- キーワード（例：`チャレンジ`）でLINE登録リンクを自動返信する設定を入れる
- **1-3 / 2-3 のアンケートで「もう決めてる」を押した人**には、3日目にDMで個別に一言送る。**ここの転換率がいちばん高い**
- インタビューで「DMやコメントを通じた密なコミュニケーションがファン化に貢献している」と確認されている。**ろっぴさんの強みなので、ここは手を抜かない**

### リール
- インタビューで**リールの投稿頻度低下が課題**として挙がっている
- ローンチ期間中に**リール1本**（3-1 or 3-2の内容を30秒で）出せると、フォロワー外への露出が乗る。任意だが効果は大きい

## 9. NGワード・表現（薬機法・景表法）

ストーリーは流れて消えるぶん油断しやすいが、**スクショは残る。** フィード投稿と同じ基準で運用する。

| 区分 | NG | 言い換え |
|---|---|---|
| 効果の断定 | 「3日で痩せます」「−◯kg確実」 | 「3日で分かるのは"あなたの数字"です」 |
| 身体の変化の保証 | 「脂肪が落ちます」「代謝が上がります」 | 「1日にやるべき量が決まります」 |
| 医療・疾患 | 「生活習慣病が防げます」「むくみが治る」 | **疾患名・治療は一切出さない** |
| 実績表記 | 「10kg痩せました」（期間なし） | **「1年で10kg」。期間を必ず添える** |
| ビフォーアフター | 加工写真／条件表示なしの比較写真 | 使うなら**期間明記＋個人の感想の注記。** 使うのは1-1の1枚だけ |
| 限定性 | 上限が無いのに「残り◯名」 | 実際に上限を設けるなら可（第5章） |
| 他社・他手法の否定 | 「マンジャロは意味がない」等の名指し | VSL①と同じ温度に留める（「一瞬だけ痩せてリバウンドするような話は、一切しません」） |
| 他者の実績 | 「参加者全員が成功」 | 数字は**実測値のみ。**「開始1時間で◯名」は実数を入れる |

**参加者の声を使う場合：** 匿名化（年齢・地名・数値を出さない）＋ 本人の許可を必ず取る。4-1が該当。

**接点をまたいで言葉が揃うと、毎回ゼロから説得しなくてよくなる。**
