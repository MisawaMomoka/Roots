# 設計意図・NGライン・チェックリスト

## 1. この5日間が解いている問題

ローンチの成否は「3日目にリンクを何人がタップしたか」ではなく、
**「3日目に、ストーリーが何人に届いたか」**でほぼ決まる。

Instagramのストーリーは、**直近で反応した人から順に上位表示される。**
つまり3〜5日目の到達率は、**1〜2日目にどれだけスタンプを押させたかの結果として後から決まる。**

だからこの構成では：

| Day | 表向き | 実際にやっていること |
|---|---|---|
| 1 | 重大発表 | **アンケート2回で反応値を作る**（配信の器を広げる） |
| 2 | 予告 | カウントダウンで**通知の予約**を取る（見ていない人を3日目に呼び戻す） |
| 3-5 | ローンチ・煽り | 1〜2日目で広げた器に、リンクを流し込む |

**1日目・2日目にスタンプを1つも置かない台本は、それだけで3日目の到達が落ちる。**
「まだ売らない日」ほど、仕掛けを必ず入れること。

## 2. 「煽り」を、どう煽らずに実装したか

ご要望は4日目・5日目が「煽り」。
ただし既存案件（前日教育動画）で確立している流儀は **「煽らず、質問と事実に変換する」**。
ゴリゴリの煽りをそのまま入れると、ろっぽさんのアカウントでは次の2つが起きる。

- 平常運転のフォロワーが**5日間で一気に冷める**（ローンチは終わってもアカウントは続く）
- 集まるのが「煽られて入った人」になり、**3日間の宿題をやらない＝体験会に来ない**

そこで、煽りの機能だけ残して形を変えた。

| 一般的な煽り（不採用） | 本台本での実装 | 置いた枚 |
|---|---|---|
| 「残り◯名！」 | **人数の限定は書かない。** 実際に上限が無いなら書けない（景表法）。期日だけで押す | 3-2 / 5-1 |
| 「もう二度とやりません」 | **「いまのところ決まっていません」。** 事実として十分機能し、後でまた開催できる | 5-1 |
| 「このままだと一生痩せません」 | **「3日後も同じことで悩んでるのは、もったいない」。** 恐怖ではなく損失の名指し | 5-3 |
| 「本気の人だけ来てください」 | **「やる、やらない、どっちでもいい」。** 逃げ道を明示して押し売り感を消す | 3-3 / 5-3 |
| 「3日で−2kg！」 | **「痩せません」と自分から言う。** 期待値を折ることで信頼を取る | 5-2 |
| 「参加者殺到中！」 | **参加者の"理由"を見せる**（数ではなく中身。全員ちがう＝個別最適の証明） | 4-1 |

### 「痩せますか？→痩せません」を5-2に置いた理由

3日間で体重は動かない。**動かないと知らずに入った人は、3日目に落胆した状態で体験会の案内を受ける。**
これは体験会の予約率に直撃する。

先に折っておけば、
- 参加前に折る ＝ 「正直な人だ」（信頼が上がる）
- 参加後に折る ＝ 「話が違う」（信頼が消える）

同じ事実でも、**言う順番だけで符号が反転する。** 5-2は絶対に削らない。
薬機法・景表法のリスクを同時に消せるので、コストはゼロ。

## 3. 最大の離脱ポイントは「シート未入力」

導線は **登録 → 目標シート入力 → 宿題** で、**シートが埋まらないと宿題が出せない＝そこで死ぬ。**
登録数だけ見ていると気づかないので、**KPIは登録数ではなくシート入力完了数**で置くこと。

台本では3箇所で先回りしている。

| 枚 | 打ち手 |
|---|---|
| 2-2 | **シートの画面スクショを、登録前に見せる。** 届いた瞬間の「なんか始まった」感を消す |
| 2-2 / 3-2 | **「1分」「入力すれば翌朝あなた専用の宿題が届く」** ＝ 作業ではなく**受け取り**として提示する |
| 3-2 | 参加手順を**3ステップで固定**（①登録 ②入力 ③翌朝宿題）。手順が見えていないものは後回しにされる |

**追加で必ずやること：** LINE登録直後の1通目を「シート入力だけ」に絞る。
挨拶・自己紹介・世界観の説明を1通目に混ぜると入力率が落ちる。**1通目 = 1アクション。**

## 4. 無料体験会を、いつ開示するか

3日間チャレンジの最終目的は無料体験会の予約。
一方でストーリー15枚では、体験会に一切触れていない。**意図的。**

- **触れない：** 参加率は最大化されるが、3日目に「聞いてない」が発生する
- **最初から言う：** 「結局セールスか」で登録率が落ちる

**推奨する着地：ストーリーでは言わない。LINE登録直後（または目標シートの最後）に、1行だけ事実として置く。**

> 「3日目に、ご希望の方だけ無料体験会のご案内をします。」

こうすると、
- ストーリーの熱は落ちない（募集の文脈に一切ノイズが入らない）
- 「聞いてない」は発生しない（登録した全員が最初に見ている）
- **「ご希望の方だけ」で逃げ道が立っている**ので、警戒されない

IBLDが体験会を初日から解放しているなら、**「3日目に案内」を「いつでも予約できます」に変えるだけ**でこの1行はそのまま使える。

## 5. ストーリー運用の実務ルール

### 文字量
- **1枚 = 1メッセージ。** 言いたいことが2つあるなら2枚に割る
- 1枚の文字数は**80字前後まで。** それ以上はスキップされる（読まれるのは平均2〜3秒）
- 文字は**大きく・少なく。** 迷ったら削る

### 配置
- **上端15%・下端20%には文字を置かない**（アカウント名とDM入力欄に隠れる）
- リンクスタンプは**中央〜やや下**
- **リンクスタンプの枚には、他のスタンプを置かない**（タップ先が割れる）

### 顔出し
- **1-1 と 5-3 は顔出し**にする（初日と最終日で対にする）
- 全15枚テキストだけだと滞在時間が伸びず、到達率が落ちる

### ハイライト
- **1枚目から全部、ハイライト「3日間チャレンジ」に保存する**
- 途中から見た人・4日目に初めて気づいた人の受け皿になる。ここが無いと後追い組を全部落とす
- ハイライトのカバーは統一する（未統一だと存在に気づかれない）

### プロフィール
- ローンチ期間中は**プロフィールURLもLINE登録リンクに変更**する
- ストーリーのリンクをタップし損ねた人が、次に行くのはプロフィール

### DM自動応答
- キーワード（例：`チャレンジ`）でLINE登録リンクを自動返信する設定を入れる
- ストーリーへの返信・スタンプ反応から**個別に拾える**

### ストーリー以外の補強（任意だが効果が大きい）
- **フィード投稿1本を3日目に。** ストーリーは24時間で消えるが、フィードは残る
- **1-3 / 2-3 のアンケートで「参加する」を押した人**には、3日目にDMで個別に一言送る。ここの転換率がいちばん高い

## 6. NGワード・表現（薬機法・景表法）

ストーリーは流れて消えるぶん油断しやすいが、**スクショは残る。** フィード投稿と同じ基準で運用する。

| 区分 | NG | 言い換え |
|---|---|---|
| 効果の断定 | 「3日で痩せます」「−◯kg確実」 | 「3日で分かるのは"自分の量"です」 |
| 身体の変化の保証 | 「脂肪が落ちます」「代謝が上がります」 | 「食べていい量が決まります」 |
| 医療・疾患 | 「生活習慣病が防げます」「便秘が治る」 | **疾患名・治療は一切出さない** |
| ビフォーアフター | 加工写真／条件表示なしの比較写真 | 使うなら**個人の感想・条件明記**。この15枚では**使わない設計** |
| 限定性 | 「残り◯名」「二度とやりません」 | 実際に上限が無いなら書かない／「いまのところ決まっていません」 |
| 実績 | 「参加者全員が成功」 | 数字は**実測値のみ。**「開始1時間で◯名」は実数を入れる |
| 他者比較 | 「他のダイエットは意味がない」 | 「やっている間だけ痩せる方法」（仕組みを名指しする） |

**参加者の声を使う場合：** 匿名化（年齢・地名・数値を出さない）＋ 本人の許可を必ず取る。4-1が該当。

### IBLDのステップ配信をもらったら、何を変えるか

**ストーリーで使った言葉を、LINEの1通目にそのまま再登場させる。**
前日教育動画で「終止符」を商談と揃えたのと同じ設計。

具体的には、
- 5-3の**「決めるだけ、決めちゃってください」**を、3日目の体験会案内に再登場させる
- 2-2の**「MEL設計」**を、ステップ配信の中で同じ定義で使う
- 4-2の**「やらない理由3つ」**を、ステップ配信の離脱防止パートで再利用する

接点をまたいで言葉が揃うと、**毎回ゼロから説得しなくてよくなる。**
IBLDの配信文をいただければ、この対応表を作ります。

| 指標 | 見る場所 | 落ちていたら |
