# 3日間 MEL設計ダイエットチャレンジ ／ 5日間ローンチ ストーリー台本

株式会社ルーツ／ろっぽさん案件。
Instagram ストーリーで **5日間 × 3枚 ＝ 全15枚** を流し、3日間チャレンジへの参加者を集めるための台本一式。

## 導線

```
ストーリー15枚 → LINE登録 → 目標シート入力 → 3日間の宿題
　　　　　　　　　　　　　　　　　　　　　　　↓（毎日21時にチェック）
　　　　　　　　　　　　　　　　　　　　　3日目：無料体験会の予約
```

**KPIは登録数ではなく「目標シートの入力完了数」。** シートが埋まらないと宿題が出せず、そこで導線が切れる。

## 5日間の構成

| Day | 表の役割 | 裏の目的 | リンク |
|---|---|---|---|
| 1 | 重大発表 | アンケートで反応値を作り、3〜5日目の到達率を上げる | − |
| 2 | 翌日の予告 | 中身を全部見せ、**目標シートの画面まで登録前に見せる** | − |
| 3 | ローンチ | 温めた人を刈る。逃げ道を明示して押し売り感を消す | ★ |
| 4 | 煽り① | 参加者の熱＋やらない理由を3つ潰す | ★ |
| 5 | 煽り②（締切） | 期限の事実だけで押す。期待値は自分から折る | ★ |

投稿は**朝8:00 / 昼12:30 / 夜21:00**に固定。
21時に揃えるのは、**チャレンジ本編の宿題チェックが毎日21時だから。** ローンチ中に21時の習慣を先に作る。

## 設計の柱

1. **1〜2日目は売らずに"器を広げる"。** ストーリーの到達率は直近の反応で決まるので、まだ売らない日ほどスタンプを必ず置く。ここを飛ばすと3日目に誰にも届かない。
2. **「煽り」は形を変えて実装した。** 残数・恐怖・「二度とやりません」は使わない。代わりに **期日の事実／参加者の理由／やらない理由の消し込み／逃げ道の明示** で押す。理由は `02-design-notes.md` 第2章。
3. **「3日で痩せますか？」に、自分から「痩せません」と答える（5-2）。** 参加前に折れば信頼になり、参加後に折れると「話が違う」になる。薬機法・景表法のリスクも同時に消える。
4. **前日教育動画と言葉を揃えた。** 5-3の「やる、やらない、どっちでもいい。決めないだけがもったいない」は、前日動画⑦と同じ文法。**接点をまたいで言葉が揃うと、毎回ゼロから説得しなくてよくなる。**
