# 3日間 MEL設計ダイエットチャレンジ ／ 5日間ローンチ ストーリー台本

株式会社ルーツ／**ろっぴさん（西岡裕子さん）**案件。
Instagramストーリーで **5日間 × 3投稿 ＝ 全15投稿** を流し、3日間チャレンジへの参加者を集めるための台本一式。

## 導線

```
ストーリー15投稿 → LINE登録 → 目標シート入力 → 3日間の宿題
　　　　　　　　　　　　　　　　　　　　　　　↓（毎日21時にチェック）
　　　　　　　　　　　　　　　　　　　　3日目：無料体験会の予約
```

**KPIは登録数ではなく「目標シートの入力完了数」。** シートが埋まらないと宿題が出せず、そこで導線が切れる。

## 前提：8月頭に1回ローンチ済み

同じアカウントで**1ヶ月前に体質診断ローンチを実施している**（8日間 → 5日目に診断リンク → LINEで結果配布 → 体質別VSL → 個別診断会）。
**今回は同じフォロワーへの2回目のローンチ。** これが設計上の最大の制約であり、同時に最大の資産。

前回VSLは「人生最後のダイエットに必要な3つの課題」を立てている。

| 課題 | 前回 | 今回の3日間チャレンジ |
|---|---|---|
| ① 自分の**体質**を正しく知ること | 診断＋VSLで**無料解決済み** | − |
| ② 体質と生活に合った**継続できる方法**を持つこと | 「この動画では答えられません」→ 診断会へ | **目標シート＋宿題がこれ** |
| ③ **独りにならない環境**を持つこと | 診断会・サポートへ | **毎日21時のチェックがこれ** |

**前回VSLを見た人は、「②と③が要る」と自分で結論を出している。** そこに無料でその一部が届く。
だから1日目は「前回の続き」として開き、4日目に21時チェックの意味を言語化する。

## 5日間の構成

| Day | 表の役割 | 裏の目的 | リンク |
|---|---|---|---|
| 1 | 重大発表 | 前回への感謝から開く。アンケートで反応値を作り、3〜5日目の到達率を上げる | − |
| 2 | 翌日の予告 | 中身を全部見せ、**目標シートの画面まで登録前に見せる** | − |
| 3 | ローンチ | 温めた人を刈る。逃げ道を明示して押し売り感を消す | ★ |
| 4 | 煽り① | **「なぜ毎日21時に聞きにいくのか」**を動画で言語化（15投稿の核） | ★ |
| 5 | 煽り②（締切） | 期限の事実と、ろっぴさん本人の言葉で決めさせる | ★ |

投稿は**朝8:00 / 昼12:30 / 夜21:00**に固定。
21時に揃えるのは、**チャレンジ本編の宿題チェックが毎日21時だから。** ローンチ中に21時の習慣を先に作る。

## 設計の柱

1. **1日目を「前回の続き」として開く。** 1ヶ月で2回目のローンチなので、前回に触れずに新企画を出すと「また何か始めた」になる。前回の体質診断への感謝から入り、**「そのあといちばん多かった質問」**として今回を出す。その質問はVSL⑩の原文（「じゃあ具体的に"私の場合"は、何から、どのくらい、どうやればいいの?」）に合わせてある。
2. **1〜2日目は売らずに"器を広げる"。** ストーリーの到達率は直近の反応で決まるので、まだ売らない日ほどスタンプを必ず置く。ここを飛ばすと3日目に誰にも届かない。
3. **4日目の昼が15投稿の核。** 「なぜ毎日21時に聞きにいくのか」を、ろっぴさん本人が喋る30〜45秒の動画で。前回VSL⑨がまるごと前振りになっている。**「私が1年で10kg落として今もリバウンドしていない一番の理由は、意志が強くなったからじゃなくて、独りにならない環境に自分から入ったから」**が背骨。
4. **「煽り」は形を変えた。** 残数・恐怖・「一歩を踏み出さなかった結果が今のあなたの体型です」は使わない。代わりに **期日の事実／参加者の理由／やらない理由の消し込み／逃げ道の明示**、そして締めに **「5年後のあなたから見たら、今日が一番若くて一番痩せやすい日です」**（VSL⑫の原文）。
5. **「3日で痩せますか？」に、自分から「痩せません」と答える（5-2）。** 参加前に折れば信頼になり、参加後に折れると「話が違う」になる。VSL①の「一瞬だけ痩せてリバウンドする話は一切しません」と同じ姿勢なので、キャラとしても一貫する。
6. **セリフはろっぴさん本人の言葉から借りる。** 新しい言い回しを発明すると、前回の配信・VSL・診断会と言葉がズレる。使う6つの決めゼリフは `03-roppi-assets.md` 第6章。

## 先に決めていただきたい3つ（★★★）

1. **3日間チャレンジのLINEは、前回の体質診断と同じアカウントか、別か。**
   同じなら、前回登録済みの人はストーリーのリンクを踏む必要がありません。**LINEからも同時配信しないと、VSLで教育済みのいちばん濃い層をまるごと落とします。**
2. **3日間の宿題の実物。** 2-1が現状は仮置きです。実物が入れば、そこが15投稿でいちばん強い枚になります。
3. **「MEL設計」という呼称を出すかどうか。** 前回「体質別・4タイプ・東洋医学」の世界観を出したばかりなので、1ヶ月後に別のフレーム名が並ぶと世界観が割れます。現行台本は**呼称を出さず「体質診断のその先」として機能だけ言う**案（`02-design-notes.md` 第4章）。
