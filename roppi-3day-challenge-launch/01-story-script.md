# 3日間チャレンジ ローンチ ストーリー台本 v2

- **媒体**：Instagram ストーリー（ろっぴさん／西岡裕子さん アカウント）
- **期間**：5日間 × 3投稿／日 ＝ **全15投稿**
- **ゴール**：LINE登録 → **目標シート入力完了**（登録だけでは宿題が出せないため、KPIはシート入力率）
- **前提**：**8月頭に体質診断ローンチ済み**（8日間 → 5日目に診断リンク → LINEで結果配布 → 体質別VSL → 個別診断会）

## v2での変更（前回ローンチのVSLとインタビューを反映）

1. **1日目を「前回の続き」として開いた。** 同じフォロワーに1ヶ月で2回目のローンチをかける。前回に触れずに新企画を出すと「また何か始まった」になる。**前回の体質診断への感謝から入り、「そのあと一番多かった質問」として今回を出す。**
2. **その質問を、VSL⑩の原文に合わせた。** VSLは「じゃあ具体的に"私の場合"は、何から、どのくらい、どうやればいいの?」と問いを立て、「それはこの動画では答えられません」と診断会に送っている。**今回のチャレンジは、その問いに無料で答える企画として位置づく。**
3. **4日目の昼を「毎日21時のチェックがある理由」に丸ごと使った。** VSL⑨（独りにならない環境）が、そのまま前振りになっている。ろっぴさん自身の「10kg痩せた一番の理由は、独りにならない環境に自分から入ったから」を核に置いた。**ここが15投稿でいちばん強い。**
4. **セリフをろっぴさん本人の言葉から借りた。** 「整える」「1日15分」「テスト前に勉強できたのは、チェックされる場があったから」「5年後のあなたから見たら、今日が一番若くて一番痩せやすい日」。詳細は `03-roppi-assets.md`。

> ⚠️ `【要確認】` は実物の情報をもらい次第そのまま差し替えます。一覧は `02-design-notes.md` の「未確定事項」。

## 全体設計

| Day | 表の役割 | **裏の目的** | リンク |
|---|---|---|---|
| 1 | 重大発表 | **前回の続きとして開く。** アンケートで反応値を作り、3〜5日目の到達率を上げる | − |
| 2 | 翌日の予告 | **ハードルを事前に消す。** 中身を全部見せ、シート画面まで先に見せる | − |
| 3 | ローンチ | **刈る。** 逃げ道を明示して押し売り感を消す | ★ |
| 4 | 煽り① | **21時チェックの価値を言語化する。** VSL⑨の圧縮版 | ★ |
| 5 | 煽り②（締切） | **決めさせる。** 期限の事実と、ろっぴさん本人の言葉で | ★ |

**時間割はチャレンジ本編と同じ「朝・昼・21時」に固定する。**
本編が毎日21時の宿題チェックなので、**ローンチ中から21時に見る習慣を作っておく。** 参加後の21時開封率がそのまま上がる。

| 枠 | 時刻 | 役割 |
|---|---|---|
| 朝 | 8:00 | 引き・問いかけ（スタンプで反応を取る） |
| 昼 | 12:30 | 中身・納得（いちばん尺を使っていい枠） |
| 夜 | **21:00** | 行動・締め（CTA・カウントダウン・リンク） |

## 1-3｜21:00｜枠の提示 ＋ 21時チェックの先出し

```
・参加費：0円
・期間：3日間
・やること：1日ひとつの宿題だけ
・かかる時間：1日5分
```

**続けて：**

```
それと、もうひとつ。

毎日21時に、私が
「今日どうでしたか」と聞きにいきます。
```

**スタンプ：** アンケート → `明日ちゃんと聞く` ／ `もう決めてる`

> **メモ：**
> - **21時チェックを初日に先出しするのが、この台本の要。**
>   前回VSL⑨で「見てくれる人がいるかどうか」を散々教育してある。だから **この一行が、前回組には"あの環境が無料で手に入る"と読める。**

# DAY 2 ── 翌日の予告

> この日の仕事は**「知らないから参加しない」を全部消すこと。**
> 出し惜しみで増えるのは期待値ではなく離脱。

## 2-1｜8:00｜3日間の中身

```
3日間で、こういうことをします。

【1日目】

【2日目】
その量で、実際に1日過ごしてみる

【3日目】
```

**続けて：**

```
制限はしません。「整える」だけです。

```

> - **「制限じゃなくて整える」はVSL③の原文。** ろっぴさんの方法論の中心なので、必ずこの言葉で言う。

```
その前に、ひとつだけ。

「運動は1時間やらないと意味がない」
これ、間違いなんです。

私がやってたのは、
1日15分のおうちエクササイズだけでした。
```

```
今回のチャレンジ、
運動の宿題はゼロです。
```

**スタンプ：** カウントダウン再掲

# DAY 4 ── 煽り①（21時チェックの価値を言語化する）

> ここでの「煽り」は残数・恐怖ではない。
> **「もう参加している人がいる」＋「なぜこのチャレンジが続くのか」**の2つで押す。

## 4-1｜8:00｜参加者の理由を見せる

```
昨日入力してもらったシート、
全部見ました。
```

```
「産後から戻らなくて」
「健康診断で引っかかった」
「来年、下の子の卒業式がある」

目標も、理由も、全員ちがう。
だから宿題も、全員ちがいます。
```

> **メモ：**
> - **必ず匿名化する。** 数値・年齢・地名を出さない。スクショを貼るなら本人の許可を取る。
> - 「全員ちがう」を見せると、**"あなたに合わせて出される"という価値**が説明ゼロで伝わる。VSL⑨の「同じ体質タイプでも、正しいやり方は一人ひとり違う」の実演。
> - 3つ目の例をあえて**「子どもの卒業式」**にしてある。ろっぴさん自身の転換点と同じで、5-3で回収できる。
> - `【要確認】` 実際に届いた回答の傾向に差し替え。届いていなければ「登録者数の報告＋よくある質問」に振り替える。

---

## 4-2｜12:30｜**なぜ毎日21時に聞きにいくのか** ★この15投稿の核

**形式：** **ろっぴさん本人が喋る動画（30〜45秒）を推奨。** テキストだと文字量が多すぎる。
動画1本＝この枠の1投稿として扱う（ストーリー側で15秒ごとに自動分割される）。

**セリフ：**

```
このチャレンジ、毎日21時に私が
「今日、宿題やれましたか？」って
聞きにいきます。

正直、面倒だと思います。
でも、ここがいちばん大事なところなんです。

学生の頃、テスト前だけ勉強できましたよね。
あれ、意志が強かったからじゃなくて、
「チェックされる場」があったからです。

ダイエットって、誰にも見られずに
たった一人でやるものなんです。

サボっても誰にも何も言われないし、
頑張っても、誰にも褒められない。
それなら楽なほうを選ぶのが、
人間として普通なんです。

私が1年で10kg落として、
今もリバウンドしていない一番の理由は、
意志が強くなったからじゃなくて、
"独りにならない環境"に、
自分から入ったからです。

3日間だけですけど、
その環境、こっちで用意します。
```

**テロップ（画面に残す3行）：**
```
続かないのは、意志が弱いからじゃない
「チェックされる場」が無かっただけ
→ 3日間、こっちで用意します
```

> **メモ：**
> - **前回VSL⑨をまるごと圧縮したもの。** 前回VSLを見た人は「独りにならない環境が必要」と**自分で結論を出している。** そこに無料でその一部が届く、という構図になる。
> - 「テスト前に勉強できたのは、チェックされる場があったから」「独りにならない環境に自分から入った」は、**どちらもVSLの原文。** 言い換えないこと。
> - **この投稿だけは動画で撮る。** 15投稿すべてテキストだと滞在時間が伸びず到達率が落ちる。ここが最も感情が動く箇所なので、声で伝える価値が最大。
> - **売り込みに転ばせない。** 締めは「3日間だけですけど、その環境、こっちで用意します」で止める。この先（診断会・サポート）には**一切触れない。**

# DAY 5 ── 煽り②（締切）

## 5-1｜8:00｜今日で締める ＋ やらない理由を潰す

```
今日 23:59 で締め切ります。
```

```
参加しない理由、
だいたいこの3つなんです。

① 時間がない
　 → 1日5分です

② 続く自信がない
　 → 3日で終わります

③ 運動が嫌い
　 → 運動の宿題はゼロです
```

```
3つとも潰したので、
あとは決めるだけです。
```

**スタンプ：** リンクスタンプ

> **メモ：** 「二度とやりません」は書かない。**やる可能性があるなら虚偽になる。**
> 次回未定であることに触れるなら「いまのところ決まっていません」に留める。

---

## 5-2｜12:30｜質問に答える（期待値を自分から折る）

```
昨日もらった質問に答えます。
```

```
Q. 3日で痩せますか？
A. 痩せません。
　 3日で分かるのは"あなたの数字"です。

Q. 食事制限がつらいのは無理です
A. 減らす宿題は出しません。
　 "整える"宿題です。

Q. 前回の体質診断、受けてないけど大丈夫？
A. 大丈夫です。今回だけで完結します。
```

> **メモ：**
> - **「3日で痩せますか？→痩せません」を自分から言うのが、15投稿でいちばん信頼が動く一言。**
>   3日で体重は動かない。知らずに入った人は3日目に落胆した状態で体験会の案内を受ける。**参加前に折れば信頼になり、参加後に折れると「話が違う」になる。** ここは絶対に削らない。
>   VSL①の「一瞬だけ痩せてリバウンドするような話は、一切しません」と同じ姿勢なので、ろっぴさんのキャラとしても一貫する。
> - **3つ目のQで前回組と新規の両方を拾う。**（前回組が少数なら 1-2 に前倒し）
> - `【要確認】` 4-3で集まった実際の質問に差し替える。

---

```
やる、やらない、どっちでもいいです。

ただ、"考えます"のまま

```

**締め（VSL⑫の原文）：**

```
5年後のあなたから見たら、
今日が、いちばん若くて、
いちばん痩せやすい日です。
```

**スタンプ：** リンクスタンプ

> **メモ：**
> - **VSL⑫にある「その一歩を踏み出してこなかった結果が、今のあなたの体型です」は使わない。**
>   VSLは「見ると決めた人」が見る60分だから成立する。ストーリーは通りすがりが見る2秒で、同じ言葉が**非難として届く。**
> - 代わりに、同じVSL⑫の**「5年後のあなたから見たら、今日が一番若くて一番痩せやすい日です」**を使う。**責めずに、同じ「今やる理由」を立てられる。** ろっぴさん本人の言葉なので、そのまま読める。
> - 「やる、やらない、どっちでもいい」で**先に逃げ道を開ける。** 逃げ道が開いていると、「決める」だけが残る。
