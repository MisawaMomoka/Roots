# 3日間チャレンジ ローンチ ストーリー台本 v1

- **媒体**：Instagram ストーリー（ろっぽさん アカウント）
- **期間**：5日間 × 3枚／日 ＝ **全15枚**
- **ゴール**：LINE登録 → **目標シート入力完了**（登録だけでは宿題が出せないため、KPIはシート入力率）
- **導線**：ストーリー → LINE登録 → 目標シート → 3日間の宿題 → 毎日21時チェック → 最終日に無料体験会予約

> ⚠️ `【要確認】` が付いた箇所は、実物の情報をもらい次第そのまま差し替えます。一覧は `02-design-notes.md` の「未確定事項」に集約。

---

## 全体設計

| Day | 表の役割 | **裏の目的** | リンク |
|---|---|---|---|
| 1 | 重大発表 | **リーチを作る。** アンケートで反応を集め、3〜5日目の到達率を上げる | なし |
| 2 | 翌日の予告 | **ハードルを事前に消す。** 中身を全部見せ、シート画面まで先に見せる | なし |
| 3 | ローンチ | **刈る。** 1〜2日目で温めた人を一気に入れる | ★リンク |
| 4 | 煽り① | **やらない理由を潰す。** 参加者の熱＋不安つぶし | ★リンク |
| 5 | 煽り②（締切） | **決めさせる。** 期限の事実だけで押す | ★リンク |

**時間割は3日間チャレンジ本編と同じ「朝・昼・21時」に固定する。**
チャレンジ本編が毎日21時の宿題チェックなので、**ローンチ中から21時に見る習慣を作っておく。**
参加後の21時開封率がそのまま上がる。

| 枠 | 時刻 | 役割 |
|---|---|---|
| 朝 | 8:00 | 引き・問いかけ（アンケート／クイズで反応を取る） |
| 昼 | 12:30 | 中身・納得（いちばん文字量を使っていい枠） |
| 夜 | **21:00** | 行動・締め（CTA・カウントダウン・リンク） |

---

# DAY 1 ── 重大発表

> この日は**まだ売らない。** アンケートを2回踏ませて、アカウントの反応値を上げるのが本当の仕事。
> ここで反応を作れていないと、3日目のローンチが誰にも届かない。

## 1-1｜8:00｜正直アンケート

**画：** 自撮り or 短い自分の動画（顔を出す枚をこの1枚に置く）

```
朝いちで、正直アンケートです。

この夏、体重どうなりました？
```

**スタンプ：** アンケート → `聞かないで😇` ／ `キープできた💪`

**下に小さく：**
```
今日、大事なお知らせがあります。
夜まで見ててください。
```

> **メモ：**「増えた／減った」で聞かない。責める形にすると押した人に罪悪感が残り、以降の3枚が全部きつく聞こえる。
> `聞かないで😇` という**逃げ道つきの選択肢**にすることで、押すのがラクになり回答率が上がる。

---

## 1-2｜12:30｜重大発表 本体

**画：** テキスト主体（背景1色、文字大きめ）

```
【重大発表】

◯月◯日から、
3日間のダイエットチャレンジを
やります。

参加費は0円です。
```

**次にスワイプさせず、同じ枚の下半分に理由を置く：**

```
ずっとDMで
「何から始めればいいですか」と
聞かれ続けてきて、

そのたび個別に返してたんですが、
正直、追いつかなくなりました。

なので、3日で
"自分の正解"が分かる形にしました。
```

> **メモ：** 発表の直後に**やる理由（＝こちらの都合）**を置くのが肝。
> 「あなたのために作りました」より「追いつかなくなったので作りました」のほうが、売り込みに聞こえない。
> `【要確認】` DMで実際に多かった質問の文言に差し替える。作り話にしない。

---

## 1-3｜21:00｜枠の提示 ＋ 明日の予告

```
・参加費：0円
・期間：3日間
・やること：1日ひとつの"宿題"だけ
・かかる時間：1日5分

中身は明日、全部話します。
```

**スタンプ：** アンケート → `明日ちゃんと聞く` ／ `もう決めてる` 

> **メモ：** 2択とも**肯定側**にする。否定の選択肢を置くと「参加しない」を自分で宣言させることになり、後から翻しにくくなる。
> ここを押した人は3日目に個別DMで拾える（`02-design-notes.md` 参照）。

---

# DAY 2 ── 翌日の予告

> この日の仕事は**「知らないから参加しない」を全部消すこと。**
> 中身を出し惜しみしない。出し惜しみで増えるのは期待値ではなく離脱。

## 2-1｜8:00｜3日間で何をするか

```
3日間で、こういうことをします。

【1日目】
あなたが1日に食べていい量を決める

【2日目】
その量で、実際に1日過ごしてみる

【3日目】
3日分の結果を見て、"続く形"に整える
```

**下に：**
```
1日にかかる時間は、5分。
運動の宿題は、ひとつも出しません。
```

> `【要確認】` **宿題の実物に合わせて全面差し替え。** 上は「回答結果と目標に合わせて宿題が出る」という設計から逆算した仮置き。
> 実際の3日分の宿題をもらえれば、ここが台本でいちばん強い枚になる。

---

## 2-2｜12:30｜なぜ3日なのか ＋ 目標シートを見せる

```
なんで3日なのか。

正直に言うと、
3日で体は変わりません。

でも、"数字"は3日で出せます。
```

**続けて：**
```
年齢・身長・今の体重・目標・
今の食習慣・運動習慣。

ここを埋めると、あなたが1日に
何をどれだけ食べればいいかが確定します。

これを【MEL設計】と呼んでます。
```

**画：** **目標シートの実際の画面スクショを貼る**（ここが最重要）

```
登録したら、まずこの画面が届きます。
入力は1分。ここが終われば、
翌朝あなた専用の宿題が届きます。
```

> **メモ：** この枚が15枚のなかで**いちばん効く。**
> 登録後の最大の離脱ポイントは「シート未入力」。フォームは登録前に見せておくと、届いた瞬間の心理的抵抗がほぼ消える。
> 「1分」は実測してから書くこと。長ければ「◯問だけ」に変える。
>
> `【要確認】` **MEL** の正式な意味（頭文字の中身）。分かればここで1行だけ開示したい。意味が伝わる略語は、伝わらない略語の3倍強い。

---

## 2-3｜21:00｜明日の募集開始を刻む

```
【明日 21時】
募集を開始します。

受付は ◯月◯日（◯）23:59 まで。

やることは2つだけ。
① LINEを登録する
② 届いたシートに入力する
```

**スタンプ：** **カウントダウンスタンプ**（明日21:00 にセット）

```
↑ これ押しといてください。
  開始したら通知が飛びます。
```

> **メモ：** カウントダウンスタンプは**このローンチの生命線。**
> 押した人には開始時に Instagram から自動通知が飛ぶ＝ストーリーを見ていなくても3日目に呼び戻せる。
> **押してもらうよう明示的に言うこと。** 黙って置いても押されない。

---

# DAY 3 ── ローンチ

## 3-1｜8:00｜最終予告 ＋ 質問を1つ潰す

```
今夜21時から。

昨日いちばん多かった質問がこれでした👇

「運動、しなきゃダメですか？」
```

```
→ いりません。

3日間、運動の宿題はゼロです。
やるのは"決めること"だけです。
```

**スタンプ：** カウントダウン再掲

> `【要確認】` 実際に来た質問に差し替える。来ていなければ、この枚は「時間がない人向け」の内容に振り替える。

---

## 3-2｜21:00｜募集開始 ★リンク

```
【募集開始】

3日間チャレンジ、受付スタートです。
```

```
① 下のリンクからLINE登録
② 届くシートに入力（1分）
③ 翌朝、あなた専用の宿題が届く

締切：◯月◯日（◯）23:59
```

**スタンプ：** **リンクスタンプ**（LINE登録URL）／ 表示テキストは `3日間チャレンジに参加する`

> **メモ：**
> - リンクスタンプは**1枚に1つ。** この枚にはアンケート等を同居させない（タップ先が分散する）。
> - リンクは**画面の中央〜やや下**。上端はプロフィール、下端はDM入力欄に食われる。
> - **人数制限を書かない。** 実際に上限が無いなら「限定◯名」は書けない（景表法）。期間の締切だけで押す。

---

## 3-3｜22:30｜初速 ＋ 逃げ道を明示する

```
開始から1時間で ◯名。
ありがとうございます。
```

```
いま多い質問：
「途中で抜けても大丈夫ですか？」

→ 大丈夫です。
  ブロックすれば、それで終わりです。

逃げ道はある状態で、
始めてください。
```

**スタンプ：** リンクスタンプ

> **メモ：** **逃げ道を先に開示するのが、押し売り感を消す最短ルート。**（前日教育動画⑦と同じ設計）
> 「抜けられない場所に入れられる」という不安は、ダイエット系の無料企画でいちばん大きい離脱理由。
> ここを自分から潰すと、登録率が上がるだけでなく、参加後のブロック率が下がる。

---

# DAY 4 ── 煽り①（不安つぶし）

> ここでの「煽り」は**残数・限定・恐怖ではない。**
> 「もう参加している人がいる」＋「やらない理由がもう無い」の2つで押す。（理由は `02-design-notes.md`）

## 4-1｜8:00｜参加者の熱を見せる

```
昨日入力してもらったシート、
ぜんぶ見ました。
```

```
「産後から戻らなくて」
「健康診断で引っかかった」
「来年の結婚式まで」

目標も、理由も、全員ちがう。

だから宿題も、全員ちがいます。
```

> **メモ：**
> - **必ず匿名化する。** 数値・年齢・地名を出さない。スクショを貼るなら本人に許可を取る。
> - ここで「全員ちがう」を見せておくと、**"自分に合わせて出される"という商品価値**が、説明ゼロで伝わる。
> - `【要確認】` 実際に届いた回答の傾向に差し替え。届いていなければこの枚は「登録者数の報告＋よくある質問」に振り替える。

---

## 4-2｜12:30｜やらない理由を3つ潰す

```
参加しない理由、
だいたいこの3つです。
```

```
① 時間がない
   → 1日5分です

② 続く自信がない
   → 3日で終わります

③ 運動が嫌い
   → 運動の宿題はゼロです
```

```
3つとも潰したので、
あとは"やるかどうか"だけです。
```

**スタンプ：** リンクスタンプ

---

## 4-3｜21:00｜締切前日 ＋ 質問を集める

```
締切まで、あと1日。
（◯月◯日 23:59まで）

迷ってることがあれば、
ここに投げてください。
明日のストーリーで全部答えます。
```

**スタンプ：** 質問スタンプ

> **メモ：** 集めた質問は **5-2の中身になる。** ここで集めておかないと最終日の昼が埋まらない。
> 質問が来なかった場合の予備は `02-design-notes.md` に3本用意してある。

---

# DAY 5 ── 煽り②（締切）

## 5-1｜8:00｜今日で締める

```
今日で受付を締めます。
（23:59まで）
```

```
次にやる予定は、
いまのところ決まっていません。
```

**スタンプ：** リンクスタンプ

> **メモ：** 「二度とやりません」は書かない。**やる可能性があるなら虚偽になる**（景表法／信用の問題）。
> 「決まっていません」で事実として十分押せる。

---

## 5-2｜12:30｜質問に答える（誇大な期待を自分から折る）

```
昨日もらった質問に答えます。
```

```
Q. 食事制限がつらいのは無理です
A. 減らす宿題は出しません。
   "決める"宿題です。

Q. 3日で痩せますか？
A. 痩せません。
   3日で分かるのは、
   "自分の量"です。

Q. リバウンドが怖い
A. だから3日目に
   "続く形"に整えます。
```

> **メモ：** **「痩せますか？→痩せません」を自分から言うのが、この15枚でいちばん信頼が動く一言。**
> 同時に薬機法・景表法のリスクを自分で消している。ここは絶対に削らない。
> `【要確認】` 4-3で集まった実際の質問に差し替える。

---

## 5-3｜21:00（or 締切2時間前）｜ラスト

**画：** 自撮り or 顔出し動画（初日1-1と対にする）

```
あと2時間で締め切ります。
```

```
やる、やらない、
どっちでもいいです。

ただ、"考えます"のまま、
3日後も同じことで悩んでるのは、
もったいないと思ってます。

決めるだけ、決めちゃってください。
```

**スタンプ：** リンクスタンプ

> **メモ：** これは前日教育動画⑦の言い回しをそのまま移植したもの。
> **やらない側の逃げ道を先に明示することで、「決める」だけが残る。**
> この言葉はチャレンジ3日目の体験会案内・体験会本番でも再登場させる。**接点をまたいで言葉を揃えると、毎回ゼロから説得しなくてよくなる。**
