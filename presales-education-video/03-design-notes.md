# 設計意図・NGライン・チェックリスト

## 1. この動画が解いている問題

ご要望は次の2つで、これは本来トレードオフの関係にある。

- **A：** 「現状維持はダメ／今決断しなきゃいけない理由／投資の教育」を入れたい
- **B：** ゴリゴリ入れると勘繰られて着座率が落ちる

Aを素直にやると「明日は高額商品を売られる」と伝わり、Bが壊れる。
そこで **A を "そのまま言わずに、前提だけ install する"** 設計にした。

| 入れたい教育 | ゴリゴリ版（NG） | 本台本での実装 |
|---|---|---|
| 投資の教育 | 「健康はコストではなく投資です」「浪費を見直しましょう」 | **過去の棚卸しに変換。**「今まで使ってきたお金のうち、今も残っているものは？」→ 答えは本人の中に出る。こちらは一言も「投資」と言わない |
| 今決断する理由 | 「今日決めてください」「先延ばしは損です」 | **「やる／やらない、どちらでもいい。決めないだけがもったいない」。** 逃げ道を明示することで押し売り感を消し、"決断の場"というフレームだけ残す |
| 現状維持はダメ | 「このままだと生活習慣病になります」 | **体の事実に限定。** 代謝・筋肉量・加齢のみ。病名・健康被害は出さない |
| モチベーション | 「本気で変わりたいなら今しかない！」 | **質問に変換。**「そもそも、なんで痩せたいんでしたっけ？」→ 理想の未来を本人に語らせる。煽らない |

### なぜ「宿題」形式が効くか

VSL ⑪ で既に **「これまで試してきたダイエットと、その結果をヒアリングします」** と告知済み。
したがって「思い出してきてください」は**完全に自然な事前準備**として受け取られ、
売り込みの前振りには見えない。

にもかかわらず、お客様は前日のうちに自分で
「累計で相当使った」「なのに何も残っていない」という結論に**自分で辿り着く。**
他人に言われた主張は反論されるが、自分で出した結論は反論されない。

商談で価格が提示された瞬間、この比較軸が自動で走る。
実際、参考商談の前田さん（58歳・介護職）も自ら
「サプリと水で月5万」「下着も買っていた」「マンジャロは月2.6万」と語っていた。
**この棚卸しを事前にやらせておけるかどうかで、価格提示の受け取られ方が変わる。**

### なぜ「未来」→「お金」の順でなければならないか

v2で宿題が2つになった。**この順番は入れ替えてはいけない。**

| | 宿題 | 性質 | 位置 |
|---|---|---|---|
| ③ | なんで痩せたいのか＝理想の未来 | 前向き・感情 | **先** |
| ④⑤ | 何を試して、いくら使ってきたか | 現実・棚卸し | **後** |

理由は3つ。

1. **勘繰り対策。** お客様が最初に受け取るメッセージが「あなたの未来の話」なら、動画全体が"自分のための連絡"に見える。逆順にすると、最初に来るのが「いくら使ったか」になり、その瞬間に「お金の話をされる」と察知される。
2. **ギャップが動機になる。** 「手に入れたい未来」を先に鮮明にしてから「これまで払ってきたのに何も残らなかった」を置くと、その落差そのものが「今度こそ違うやり方で」の理由になる。逆順だとただの反省会で終わる。
3. **感情の山と谷。** ③で上げ、⑤前半で落とし、⑤後半（「明日はその逆の話をします」）で戻す。この起伏があるから⑥の「決めて帰ってきてください」が重すぎずに届く。⑤で沈んだまま⑥に入ると、決断を促す言葉が圧に変わる。

### ③が商談側にもたらすもの

③の「だから明日、いちばん最初にこれをお聞きします」は、**診断会の冒頭質問の予告**になっている。効果は動画側ではなく商談側に出る。

- お客様が**自分の答えを用意した状態で着座する**ため、商談の立ち上がりが一段あたたかくなる
- 価格提示に至るまでに、お客様側の**感情の投資**が積まれている
- VSL ⑪ の「カウンセリングシートを一緒に埋めながら現在地を把握します」とも矛盾しない

商談担当者への申し送りが1つ増える：**開口一番に「なんで痩せたいと思ったんですか」を聞く。** 動画で予告した質問が来ないと、動画の効果がそこで切れる。

## 2. NGワード・禁止事項

台本・テロップ・LINE文すべてに適用。

### 絶対に入れない

- **金額・プラン・分割・支払い方法**に関する一切の言及
  （「安くはありません」等の"匂わせ"も含めてNG。匂わせが一番勘繰られる）
- **副業・在宅ワーク・お金を稼ぐ話**（商談内で紹介されているスキームには一切触れない。
  動画という残る媒体で提示するのは特商法・与信の観点でリスクが大きい）
- **「無料」の強調**（VSLで既出。前日にもう一度言うと「無料なのに何かある」と勘繰られる）
- **限定・残枠・締切**（VSL ⑫ で使用済み。予約済みの人に再度使うと不信につながる）

### 表現に注意

| NG | OK |
|---|---|
| 「マンジャロは危険」「薬は意味がない」 | 医薬品には言及しない |
| 「必ず痩せます」「〇kg落ちます」 | 効果の断定をしない |
| 「病気になります」 | 「代謝も筋肉量も、今日がいちばん高い」 |
| 「投資」「浪費」 | 「残るもの／戻ってしまうもの」 |
| 「決断してください」 | 「決めて帰ってきてください（やらない、でもいい）」 |

### 薬機法・景表法

- 本台本には**具体的な効果効能の標榜が含まれていない**（体質・食材・数値の話をすべて排除済み）。
  そのため VSL 本編より遥かにリスクが低い。
- 「代謝・筋肉量は加齢とともに低下する」は一般的な生理学的事実の範囲。
  それでも念のため、**公開前に管理栄養士の監修チェックを1回通す**ことを推奨。

## 3. 着座率へのリスクと対策

現状「無断キャンセルはあまりない」とのことなので、**この動画は着座率を上げるためではなく、
"落とさずに教育を差し込む" ことが目的**になる。したがって以下を守る。

| リスク | 対策（台本内での実装箇所） |
|---|---|
| 営業動画だと察知される | 金額・限定・煽りをゼロにする。BGMなし、ワンカット、凝った編集をしない |
| 「宿題」が面倒でキャンセル | 「メモしてこなくて大丈夫」「そういえば、あれもやったな くらいでOK」を必ず添える（LINE 3通目） |
| 宿題が2つで負担に感じる | どちらも「考えてくるだけ」に留め、書き出しを求めない。LINE 3通目で①を先・②を後に置き、①は質問形式にして"作業感"を出さない |
| ③が説教くさく響く | 「忘れたまま方法だけ探すから、続かない」の主語は方法であって本人ではない。BGMを入れない。列挙3行はゆっくり、間を取る |
| 尺が長くて離脱 | 冒頭12秒以内に「2分だけ」と宣言。3分を超えない |
| 当日の担当者が違って不信 | ② で予告、LINE 4通目で担当者名を明示 |
| 動画を見ない人がいる | LINE 3通目のテキストで宿題だけは必ず届く二重構造 |

## 4. 効果測定

導入前後で以下を比較する。動画単体ではなく、**商談側の変化で測るのが本筋**。

| 指標 | 見るポイント |
|---|---|
| 着座率 | **下がっていないこと**が合格ライン（上がれば上出来） |
| 商談中の自己開示量 | 「過去にいくら使ったか」をお客様が**自分から**話し始めるか |
| 価格提示後の初期反応 | 「高い」ではなく「なるほど」「考えます」に変わるか |
| 成約率 | 特に **「持ち帰って考えます」で終わる商談の比率** の変化 |

最低20〜30件は回さないと有意差は見えない。
先に落とすべきは着座率ではなく「即決率」なので、そこを主指標に置く。
