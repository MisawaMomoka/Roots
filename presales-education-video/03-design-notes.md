# 設計意図・NGライン・チェックリスト

## 1. この動画が解いている問題

ご要望は次の2つで、これは本来トレードオフの関係にある。

- **A：** 「現状維持はダメ／今決断しなきゃいけない理由／投資の教育」を入れたい
- **B：** ゴリゴリ入れると勘繰られて着座率が落ちる

Aを素直にやると「明日は高額商品を売られる」と伝わり、Bが壊れる。
そこで **A を "そのまま言わずに、前提だけ install する"** 設計にした。

| 入れたい教育 | ゴリゴリ版（NG） | 本台本での実装 |
|---|---|---|
| 投資の教育 | 「健康はコストではなく投資です」「浪費を見直しましょう」 | **過去の棚卸しに変換。**「今まで使ってきたお金のうち、今も残っているものは？」→ 答えは本人の中に出る。こちらは一言も「投資」と言わない |
| 今決断する理由 | 「今日決めてください」「先延ばしは損です」 | **「やる／やらない、どちらでもいい。決めないだけがもったいない」。** 逃げ道を明示することで押し売り感を消し、"決断の場"というフレームだけ残す |
| 現状維持はダメ | 「このままだと生活習慣病になります」 | **体の事実に限定。** 代謝・筋肉量・加齢のみ。病名・健康被害は出さない |
| モチベーション | 「本気で変わりたいなら今しかない！」 | **質問に変換。**「改めて、なんで痩せたいと思ったんでしたっけ？」→ 理想の未来を本人に語らせる。煽らない |
| 投資の教育（締め） | 「自分への投資だと思って参加してください」 | **参加条件に変換。**「これを、最後の一回にするつもりで来ること」→ ①②と同じ文法で並べ、3つ目だけ性質が違うと気づかせない |

### なぜ「宿題」形式が効くか

VSL ⑪ で既に **「これまで試してきたダイエットと、その結果をヒアリングします」** と告知済み。
したがって「思い出してきてください」は**完全に自然な事前準備**として受け取られ、
売り込みの前振りには見えない。

にもかかわらず、お客様は前日のうちに自分で
「累計で相当使った」「なのに何も残っていない」という結論に**自分で辿り着く。**
他人に言われた主張は反論されるが、自分で出した結論は反論されない。

商談で価格が提示された瞬間、この比較軸が自動で走る。
実際、参考商談の前田さん（58歳・介護職）も自ら
「サプリと水で月5万」「下着も買っていた」「マンジャロは月2.6万」と語っていた。
**この棚卸しを事前にやらせておけるかどうかで、価格提示の受け取られ方が変わる。**

---

### モチベーション喚起ブロック（⑥）を「後半」に置いた理由

⑥「改めて、なんで痩せたいと思ったんでしたっけ？」は、動画の**後半・決断のお願いの直前**に置いている。

| | ブロック | 感情 |
|---|---|---|
| ③④ | これまで何に、いくら使ってきたか | **落とす**（痛み・現実） |
| ⑤ | だから明日は、その逆の話をします | 転換 |
| ⑥ | なんで痩せたいのか → 理想の未来 | **上げる**（最高潮） |
| ⑦ | 決めて帰ってきてください | 決断 |

理由は3つ。

1. **決断のお願いが、感情のピーク直後に来る。** ⑥が前半にあると、⑦の「決めて帰ってきてください」は"痛み"の余韻の中で聞くことになり、圧に変わる。後半に置いたことで「その未来のために、明日決めましょう」という自然な接続になった。
2. **同じ60分の価値が跳ね上がる。** ③④で「過去に消えたもの」を見せた直後に⑥で「これから手に入るもの」を置くので、明日の60分が"取り返す場"として立ち上がる。順序が逆だとこの対比が生まれない。
3. **⑦の損失表現が具体になる。** ⑥で「手に入れたい未来」を鮮明にしてあるから、⑦の「1年後も同じことを悩んでいます」が抽象的な脅しではなく、**名前のついた損失**として響く。⑥と⑦はセットで効く。

### 3つ目のお願いに投資の教育を隠す（⑧）

⑧は「当日の準備リスト」ではなく **「参加のお願い3つ」** にしてある。みっつ目が投資の教育。

> ひとつ、邪魔されない場所で、時間をしっかり確保すること。
> ふたつ、本気で痩せたいという想いで参加すること。
> **みっつ、これを、最後の一回にするつもりで来ること。**

勘繰られない理由は4つ。

1. **「参加条件」という枠が最強の防御。**「〜してください」ではなく「〜のつもりで来てください」なので、**何も売られていない。** ひとつ・ふたつと同じ文法で並ぶため、3つ目だけ性質が違うことに気づかれない。
2. **「最後の一回」＝もう二度と払わない。** 何度も払い続けるもの（消えるお金）と一度で終わるもの（残るもの）の対比を、参加条件の形で言い直しているだけ。**金額・プラン・「投資」「お金」という語はゼロ。**
3. **③④で棚卸しを済ませてある。** こちらは「最後の一回」としか言っていないのに、視聴者の頭では「あれだけ使ってきたお金と時間を、今回で終わりにする」に自動変換される。**自分で変換した結論は反論されない。**
4. **⑤の「終止符」と一直線。** 動画の締めが、蒲田さんが商談で使う自社コンセプトの言い換えで終わる。

**撮影時の絶対条件**：3つとも同じ調子・同じ速さで読む。**みっつ目だけ力むと、そこに意図があることが伝わる。** 淡々と3つ並べるのが最大の防御。

#### 採用しなかった案

| 案 | 判断 |
|---|---|
| 消えていくものじゃなく、ずっと残るものを持ち帰るつもりで来ること | 意味は同じだが説明的で長い（37字）。「最後の一回」のほうが短く強い |
| これからの1年を、どこに使うか決めるつもりで来ること | リソース配分＝投資の概念だが抽象的 |
| 自分への投資だと思って参加すること | **不可。** 即バレする |
| これから何にお金を使うか、見直すつもりで来ること | **不可。** 締めで「お金」を出すと、視聴後の印象が「お金の話をされた」で終わる。動画で最もやってはいけない |

#### ふたつ目の「強い」を外した理由

VSL ⑫ で既に「本気で変わりたい人だけ、来てください」と言っている。**予約済みの人に前日もう一度強く言うと「私は歓迎されていない？」と読まれる余地**があるため、「お願い」のトーンに留めた。

なお⑦の「やらない、でも全然いい」と⑧の「本気の想いで」は矛盾しない（**やるかどうかは自由／60分は本気で向き合ってほしい**）。ただし詰問の調子になると逆に聞こえるので、⑧は必ずお願いの調子で読む。

### 言葉は商談から借りる

④⑤の言い回しは、**商談で蒲田さんが実際に使っている表現**に揃えてある。

| 台本 | 商談での実際の発話 |
|---|---|
| やっている間だけ、痩せる方法 | 「パーソナルも、**行った時だけ痩せる**っていうのが、もうこれあるあるなんですよね」 |
| 痩せては戻っての繰り返しに、**終止符**を打つ | 「**ダイエットに終止符**」（自社コンセプト）／「痩せては太ってっていうこの**輪廻に終止符**を打てれば」 |
| ずっとあなたのものです | 「今後**一生使えるもの**になっていく」 |

理由は2つ。

1. **接点をまたいで言葉が揃う。**「終止符」は蒲田さんが商談で必ず口にする自社コンセプトの言葉。前日動画で先に耳に入れておくと、商談で同じ言葉が出たときに「聞いたことがある」状態になり、話が早い。
2. **抽象語を避けられる。**「やめたら戻る方法」は受け身の名詞化で、何が問題なのかが見えない。「やっている間だけ、痩せる方法」は**仕組みそのものを名指し**していて、「じゃあ、やめられないじゃないか」まで一息で伝わる。

まだ使っていない候補（尺が空いたとき用）：

- 「**一生続けるって言われたら、何のために生きてるか分からなくなる**」— 蒲田さんの発話。前田さんが最も強く同意した箇所のひとつ。④の直後に置くと効くが、35字前後かかる。
- 「無理我慢が**プツンって切れた瞬間**に、戻っていっちゃう」— 蒲田さん。「やっている間だけ」と機能が重なるので併用はしない。

### 代わりに増したリスク：③が0:28と早い

お金の話（③）が動画の序盤に来る構成なので、**③の言い方が以前より重要になった。**

- 「これまでのダイエットを思い出してきてください」という**ヒアリングの事前準備**の枠を絶対に外さない（VSL ⑪ で告知済みの内容なので、この枠内なら自然に聞こえる）
- 金額は「方法・時間・金額」の3項目のうちの1つに留め、**単独の見出しにしない**
- トーンを一段落として、責める調子を出さない

この3つが守られていれば、序盤に置いても売り込みの前振りには聞こえない。守られないと、動画の一番早い段階で勘繰られるので、**撮影時に最も注意すべきブロック。**

### ⑥が商談側にもたらすもの

⑥の「改めて、なんで痩せたいと思ったんでしたっけ？」は、**診断会の冒頭ヒアリングの予告**になっている。効果は動画側ではなく商談側に出る。お客様が自分の答えを用意した状態で着座するため商談の立ち上がりが一段あたたかくなり、価格提示に至るまでにお客様側の感情の投資が積まれている。VSL ⑪ の「カウンセリングシートを一緒に埋めながら現在地を把握します」とも矛盾しない。

**商談担当者への申し送り**：ヒアリングで必ず「なんで痩せたいと思ったんですか」を聞く。動画で予告した質問が来ないと、動画の効果がそこで切れる。

## 2. NGワード・禁止事項

台本・テロップ・LINE文すべてに適用。

### 絶対に入れない

- **金額・プラン・分割・支払い方法**に関する一切の言及
  （「安くはありません」等の"匂わせ"も含めてNG。匂わせが一番勘繰られる）
- **副業・在宅ワーク・お金を稼ぐ話**（商談内で紹介されているスキームには一切触れない。
  動画という残る媒体で提示するのは特商法・与信の観点でリスクが大きい）
- **「無料」の強調**（VSLで既出。前日にもう一度言うと「無料なのに何かある」と勘繰られる）
- **限定・残枠・締切**（VSL ⑫ で使用済み。予約済みの人に再度使うと不信につながる）

### 表現に注意

| NG | OK |
|---|---|
| 「マンジャロは危険」「薬は意味がない」 | 医薬品には言及しない |
| 「必ず痩せます」「〇kg落ちます」 | 効果の断定をしない |
| 「病気になります」 | 「代謝も筋肉量も、今日がいちばん高い」 |
| 「投資」「浪費」 | 「残るもの／戻ってしまうもの」 |
| 「決断してください」 | 「決めて帰ってきてください（やらない、でもいい）」 |

### 薬機法・景表法

- 本台本には**具体的な効果効能の標榜が含まれていない**（体質・食材・数値の話をすべて排除済み）。
  そのため VSL 本編より遥かにリスクが低い。
- 「代謝・筋肉量は加齢とともに低下する」は一般的な生理学的事実の範囲。
  それでも念のため、**公開前に管理栄養士の監修チェックを1回通す**ことを推奨。

## 3. 着座率へのリスクと対策

現状「無断キャンセルはあまりない」とのことなので、**この動画は着座率を上げるためではなく、
"落とさずに教育を差し込む" ことが目的**になる。したがって以下を守る。

| リスク | 対策（台本内での実装箇所） |
|---|---|
| 営業動画だと察知される | 金額・限定・煽りをゼロにする。BGMなし、ワンカット、凝った編集をしない |
| 「宿題」が面倒でキャンセル | 「メモしてこなくて大丈夫」「そういえば、あれもやったな くらいでOK」を必ず添える（LINE 3通目） |
| 宿題が2つで負担に感じる | どちらも「考えてくるだけ」に留め、書き出しを求めない。LINE 3通目に「メモしてこなくて大丈夫」を必ず添える |
| お金の話が序盤（0:28）に来る | ③を「ヒアリングの事前準備」の枠から絶対に外さない。金額は3項目の1つに留め、単独の見出しにしない。トーンを一段落とす |
| ⑥が説教くさく響く | 責めではなく問いかけに徹する。BGMを入れない。列挙3行はゆっくり、間を取る |
| ⑧のみっつ目で意図がバレる | 3つとも同じ調子・同じ速さで読む。みっつ目だけ力まない。「お金」「投資」を絶対に言わない |
| ⑧が詰問に聞こえる | 「お願い」の調子で。条件提示になると⑦の「やらない、でも全然いい」と矛盾して感じられる |
| 尺が長くて離脱 | 冒頭12秒以内に「2分だけ」と宣言。3分を超えない |
| 当日の担当者が違って不信 | ② で予告、LINE 4通目で担当者名を明示 |
| 動画を見ない人がいる | LINE 3通目のテキストで宿題だけは必ず届く二重構造 |

## 4. 効果測定

導入前後で以下を比較する。動画単体ではなく、**商談側の変化で測るのが本筋**。

| 指標 | 見るポイント |
|---|---|
| 着座率 | **下がっていないこと**が合格ライン（上がれば上出来） |
| 商談中の自己開示量 | 「過去にいくら使ったか」をお客様が**自分から**話し始めるか |
| 価格提示後の初期反応 | 「高い」ではなく「なるほど」「考えます」に変わるか |
| 成約率 | 特に **「持ち帰って考えます」で終わる商談の比率** の変化 |

最低20〜30件は回さないと有意差は見えない。
先に落とすべきは着座率ではなく「即決率」なので、そこを主指標に置く。
