# 診断会 前日教育動画（2〜3分）

株式会社ルーツ／ゆうなりさん案件。
体質診断VSL → 個別体質診断会（Zoom 60分）の導線で、**診断会の前日**に公式LINEで配信する
2〜3分の教育動画一式。

## 目的

診断会の着座率を落とさずに、以下3つの前提をお客様に install する。

1. **現状維持はダメ** — 恐怖ではなく「代謝・筋肉量は今日がいちばん高い」という体の事実で
2. **今決断しなきゃいけない理由** — 「明日は決める日。やる／やらないどちらでもいいが、"考えます"はもったいない」
3. **投資の教育** — 「投資」という言葉を一切使わず、**過去のダイエット費用の棚卸し**という形で
   「やめたら戻るものには、いくら払っても何も残らない」という比較軸だけを置いてくる

## 前提条件

- 話者：ゆうなりさん（顔出しトーク、VSLと同じセット・服装を推奨）
- 配信：公式LINE ステップ配信、診断会の**前日 19:00**
- 4体質タイプ共通で使用可（体質の話をしていないため）
- 尺：2分50秒前後（2分30秒まで詰める指示あり）
