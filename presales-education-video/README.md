# 診断会 前日教育動画（2〜3分）

株式会社ルーツ／ゆうなりさん案件。
体質診断VSL → 個別体質診断会（Zoom 60分）の導線で、公式LINEで配信する動画の台本一式。

| 配信タイミング | 動画 | 尺 | 役割 |
|---|---|---|---|
| **予約完了 直後** | [予約直後動画](04-booking-thanks-script.md) | 2分34秒 | 褒めて決断を固定。**教育は入れない** |
| **診断会の前日** | [前日動画](01-script.md) | 3分00秒 | 投資の教育・決断の理由・モチベーション |

## 目的

診断会の着座率を落とさずに、以下4つの前提をお客様に install する。

1. **モチベーション** — 「改めて、なんで痩せたいと思ったんでしたっけ？」で理想の未来を再点火する。煽らず、質問に変換
2. **現状維持はダメ** — 恐怖ではなく「代謝・筋肉量は今日がいちばん高い」という体の事実で
3. **今決断しなきゃいけない理由** — 「明日は決める日。やる／やらないどちらでもいいが、"考えます"はもったいない」
4. **投資の教育** — 「投資」という言葉を一切使わず、2箇所に分けて置く
   - ④⑤：**過去のダイエット費用の棚卸し**（「やっている間だけ痩せる方法には、いくら払っても何も残らない」）
   - ⑧：**参加のお願いの3つ目**（「これを、最後の一回にするつもりで来ること」）

宿題は2つ。動画では**「お金の棚卸し」が先（③④）、「理想の未来」が後（⑥）**。
モチベーションを決断のお願いの直前に置くことで、感情のピーク直後に⑦が来る（理由は設計ドキュメント）。

## 2本の役割分担

予約直後は**上げっぱなし**、前日は**落として・上げて・決断へ**。
予約直後に教育を入れると「やっぱりやめようかな」に直結するので、**ここは純粋な褒めに振り切る。**
そのぶん前日動画の緩急が効くようになる。

## 前提条件

- 話者：ゆうなりさん（顔出しトーク、VSLと同じセット・服装を推奨）
- 配信：公式LINE ステップ配信、診断会の**前日 19:00**
- 4体質タイプ共通で使用可（体質の話をしていないため）
- 尺：セリフ実測876字 ＝ ちょうど3分00秒（話速292字/分）

## 撮影前に必ずやること

- [ ] `03-design-notes.md` の **NGワード一覧** に台本・テロップ・LINE文を照らす
- [ ] 管理栄養士による監修チェック（1回）
- [ ] LINE 3通目の宿題テキスト（棚卸し・未来の両方）を、**動画を見ない人向けの保険**として必ず配信設定に含める
- [ ] ③のトーンを確認する（お金の話が0:25と早いので、責める調子が出ていないか）
- [ ] ⑧の3つを同じ調子・同じ速さで読めているか（みっつ目だけ力むと意図がバレる）
- [ ] 商談担当者に申し送り：**ヒアリングで必ず「なんで痩せたいと思ったんですか」を聞く**（動画で予告している）
